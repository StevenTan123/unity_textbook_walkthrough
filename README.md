# Unity Textbook Walkthrough

This repo contains my Unity project that I've been working on following the Unity textbook chapters. 

## How to Test

Running the Unity project is pretty self-explanatory. Import the Unity project and just press play. The project currently contains the behaviors described in chapters 1, 2, 5, 6. So you can use WASD to move the player around, use the mouse to look around, and left click to shoot red bullets.

There is an enemy spawner which spawns enemies every 5 seconds. The enemies don't currently do anything. They just spawn in and move around sporadically (technically they only have a forward movement component, but since I added rigid body physics they fall over and spazz out).
